    定稿要改的
    1. 托盘短一点：现在托盘伸出太多，像个抽屉；吐出的纸应该是主角。
    2. 按键稍大，离屏幕近一点，右边留白少一些。
    3. 顶面多露一点，让顶缝和进纸看得清。
    4. 透明背景、最大尺寸、屏幕完全关闭。
    AI 分析

    3. 懂：屏幕把认出的能力一个个锁上。
    4. 找：数字从全部 41 张卡滚到符合的张数，再到选中的张数（正式版用真实数字）。

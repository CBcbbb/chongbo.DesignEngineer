三个想法共用的规则

开始
跟随系统。第一次点：切到另一种，并记住（localStorage，读写都包在 try/catch 里）。
回到系统
不加第三个状态。只要你切回的那一种和系统一样，就自动清掉记住的选择，重新跟随系统。所以"点两次"就是"回到系统"。点完后图标下面出现一行小字说清楚现在的状态：Dark mode / until you switch back 或 Light mode / following your system（文案提案）。
读屏名
说它要做什么：Switch to dark mode / Switch to light mode，切换后的小字也会读出来。
键盘和手机
聚焦和悬停一样；44px 点击区；手机上没有悬停，动作只在点的时候发生。
减少动效
图标直接换成另一种状态，页面直接换色，不淡入。
不闪
正式版在 <head> 里放一小段内联脚本，在第一次绘制前读出记住的选择，设置 <html data-theme>。
物件不变
打印机和打印出来的纸两种模式下颜色都不变（playbook §7）。

三个想法的区别

1 拉绳灯
一盏吊灯，灯罩边上挂一根拉绳。点：拉绳往下 3px，在最低点灯亮或灭，拉绳带一点回弹弹回（共 0.5 秒）。深色模式下灯是亮的：灯泡暖黄，灯罩下一束淡淡的光，灯丝先闪两下再稳住。天黑了才开灯，所以说得通。和锤子一样是"手里的动作"。我推荐这个。
2 睡着的眼睛
一只眼睛，深色时闭上并飘出两个 z。可爱，但导航里已经有 About 的一双眼睛，再加一只会抢戏，也容易被看成"隐藏"或"查看"的意思。
3 复写纸
一张小纸翻面：正面是白纸，背面是深色的复写纸（0.45 秒 3D 翻转，带一点过冲）。最贴"打印"这个主题，但 22px 时翻面的立体感不太明显，也比灯泡难一眼看懂是开关。
